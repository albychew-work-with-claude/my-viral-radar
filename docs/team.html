SOP-01 · Marketer weekly topic picking (Monday, about 30 min)

  1. Open Viral Radar and click the quick filters "True viral ×2+" + "Last 7 days"
  2. Check "Trending tags" to set this week's theme (the more a tag appears, the higher its priority)
  3. Pick 3–5 posts worth adapting. Criteria: topic fits us / hook can be reused / we can actually film it
  4. Click "Brief" on each to copy it → send it to the filming group
  5. Drag the chosen cards to "Filming"
  6. Drag clear misfits to "Skipped". Keep the New pile as small as possible

SOP-02 · Content Creator filming and adapting (≤1 day per post)

  1. Open the Workspace "Today" tab, check the Filming queue, start with the oldest
  2. Watch the original 3 times: 1st for the whole / 2nd to break down the hook (why the first 3 seconds make people stop) / 3rd to note the structure (how many shots, what pace)
  3. Adapt, don't copy: swap in our examples, voice and industry. Keep the structure, replace the content
  4. Film → edit. The first 3 seconds must have a hook, with captions from the start
  5. After posting, come back to the Workspace and click "Done" on it

SOP-04 · How to learn from posts tagged "Bait"

For posts tagged "Bait", the point is the funnel, not the content. Note three things:

  1. What is the comment keyword? (e.g. comment "Start")
  2. What is the giveaway? (template / course / checklist)
  3. Where does it lead next? (DM auto-reply → link → sign-up page)

For a good tactic, reuse the structure and build it with our GHL / ManyChat.

SOP-05 · Managing the competitor list (add good accounts when you find them)

  1. Open the Supabase "competitors" table and add a row
  2. Username: paste the account name or the IG profile link (a ?igsh= tail is fine; don't paste a post link)
  3. Tracker: choose IG Competitors or AI Competitors
  4. Active: tick ✅ — unticked accounts are not scraped
  5. Takes effect automatically every Monday. To stop tracking, untick it; no need to delete the row

Criteria for adding an account: related to our field / content has viral potential / worth learning from. If an account in the radar goes a long time without a viral post, untick Active to free up budget for a new one.

SOP-06 · First-time setup & FAQ

  1. Set who you are: the first time you open the Workspace it asks "Who are you?" → enter your name and pick a role. This decides which task cards and layout you see
  2. Change status directly: in the radar, drag a card onto a tab above, or use the card's dropdown. A green ✓ means it worked. No key needed — the system only allows status changes and cannot touch other data, so it is safe without a login
